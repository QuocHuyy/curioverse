## Context

Large language models answer fluently, but they know nothing about *your* documents. **RAG** (Retrieval-Augmented Generation) fixes that: before answering, the system finds the most relevant passages in a document store and hands them to the model as context.

This project builds such a system for **Vietnamese PDF documents**. I followed a tutorial from [AI VIET NAM](https://aivietnam.edu.vn), then split it into clear modules and added a web UI.

## Architecture

```text
PDF ──▶ Clean & chunk ──▶ Embeddings ──▶ ChromaDB
                                            │
Question ───────────────────▶ Retrieve top-k┘
                                            │
                              Qwen 2.5 ◀────┘ ──▶ Answer
```

## Key choices

| Component | Default |
| --- | --- |
| Chunking | 400 characters, 120 overlap |
| Embeddings | `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` |
| Vector store | ChromaDB |
| Retrieval | top-k = 4 |
| Generator | `Qwen/Qwen2.5-3B-Instruct`, temperature 0.2, up to 450 tokens |

```python
from main import build_rag_system, answer_question

rag_chain = build_rag_system("/path/to/pdf/folder")
print(answer_question(rag_chain, "What is RAG?"))
```
