Font đầy đủ (TTF) chỉ dùng để sinh ảnh chia sẻ (Open Graph) lúc build.
satori chưa đọc được woff2 và không tự ghép glyph giữa các file subset, nên cần bản TTF có đủ dấu tiếng Việt.

Các file ở đây đã được cắt gọn (subset) còn Latin + tiếng Việt bằng `fontTools` để repo nhẹ;
Handjet được "đóng băng" ở độ đậm 700 (trục ELSH 2 = điểm ảnh vuông) vì satori không hỗ trợ font biến thiên.

- M PLUS Rounded 1c (mô tả): SIL Open Font License 1.1 (xem OFL-MPLUSRounded1c.txt)
- VT323 (nhãn nhỏ): SIL Open Font License 1.1 (xem OFL-VT323.txt)
